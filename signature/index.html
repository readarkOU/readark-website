Mail signatures

Press Copy, then in Gmail open Settings → See all settings → General → Signature, create a signature and paste. Set it for new mails and replies, save at the bottom. Gmail keeps the formatting as long as you paste, not retype. The logo loads from the readark site, so it needs no attachment.
